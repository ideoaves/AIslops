# AIslops
小さなツールの置き場。このリポジトリに含まれるファイルは MIT-0 ライセンス。
外部ライブラリ(three.js、PySide6、opencv など)やフォント(Google Fonts)は含まれてないです。
# ツール一覧
## ノードメモ
ノード型のメモ帳、現在はObsidianのcanvasを利用するため不要になった。
## ポモドーロ
古のWindowsのデザインのポモドーロタイマー。
- Python 3 (tkinter) 利用。
## slitscan
動画のスリットスキャンを行うツール。1pxを超える幅をグラデーションに合成する。
- Python 3, PySide6, opencv-python, numpy
## kirinuki-telop
ページの文字を切り抜き動画風テロップにする Chrome 拡張
## 画像管理ツール
画像にタグ・年代・場所を付けて管理する。リファレンスの雑な収集用途。現在は特徴量ソートツールがあるため不要。
- Python 3, Pillow, opencv-python。
## space_game
相対論と惑星を扱うブラウザゲーム。光速に近いと景色が歪む、というだけです。あとバグあり。
## WebM変換
動画を WebM などに変換・切り出しする。
- Python 3, PySide6, ffmpeg
